# 고양이 표정과 네발 바디랭귀지

## 현재 표정 계약

SEMI의 입은 코→짧은 인중→좌우 곡선으로 연결된 닫힌 선이다. 음성·놀람에도 구강 채움·혀·입 벌림을 만들지 않는다. 수염은 양쪽 세 가닥의 짧고 펴진 부채꼴이며 윗가닥을 더 짧게 한다. 일반 상태는 각도·길이·위상차로 움직이고 강한 긴장·명시적 충격에서만 제한된 수축·물결을 허용한다. 눈을 피하려고 가닥 중간을 꺾거나 세 선을 평행한 막대로 만들지 않는다. 정확한 도면 수치는 SEMI 구현이 소유한다.

## 행동 근거와 각색

- [Cats Protection](https://www.cats.org.uk/help-and-advice/cat-behaviour/cat-body-language): 이완·호기심·불안·낙담의 눈·귀·수염·자세를 함께 살핀다. 호기심과 불안 모두 수염이 앞쪽을 향할 수 있어 수염 하나로 감정을 구분하지 않는다. 자료의 삽화는 보행 타이밍·관절 궤적을 제공하지 않는다.
- [VCA](https://vcahospitals.com/know-your-pet/why-do-cats-have-whiskers): 수염은 감각 구조다. 만화의 세 가닥 개수와 찌릿한 물결은 캐릭터 연기를 위한 선택이다.
- [Scott & Florkiewicz, 2023](https://doi.org/10.1016/j.beproc.2023.104959): 사회적 맥락과 얼굴 동작의 조합을 분석한 연구다. 특정 만화 감정이나 곡선을 검증한 결과로 해석하지 않는다.
- [Feline Grimace Scale](https://www.felinegrimacescale.com/science-and-research)는 급성 통증 평가 자료이며 일반 감정 분류표가 아니다.
- [만화 입·수염 도면 참고](https://howtodrawforkids.com/how-to-draw-a-cat-nose-and-whiskers/): 코 밑 연결선, 좌우 입 곡선과 수염이라는 단순한 그림 구조를 참고한다.

## 다음 구현 범위: 네발 전신

현재 문서 고양이와 별도로 수평 몸통·척추·목·어깨·골반·네 다리·발·꼬리의 구조화된 포즈가 필요하다. 기존 상태·presentation clock·scene·renderer 경계는 [architecture](ARCHITECTURE.md)를 따른다. 지면 기준의 발 접촉과 몸체 변형을 계산한 뒤 화면 맞춤 변환을 적용한다. 현재 전체 surface transform이나 document transform에 지지 중인 발을 묶지 않는다.

아래는 출처의 정지 단서를 캐릭터 동작으로 옮기는 설계이며 아직 구현되지 않았다.

| 동작 | 전신 연기 |
|---|---|
| 편안함 | 안정된 네발 지지·호흡·작은 체중 이동·느린 깜빡임 |
| 친근함 | 꼬리를 세워 짧게 접근한 뒤 멈춤 |
| 호기심 | 목과 고개를 앞으로 내밀고 앞쪽 체중 이동 |
| 불안 | 낮은 자세·주변 살피기·조심스러운 후퇴 |
| 방어 | 둥근 등선과 부풀린 털·꼬리 실루엣 |
| 낙담 | 고개·귀·수염을 낮추고 느린 움직임 |

먼저 서기·걷기·멈춤과 전환을 검증한다. 구르기·볼 비비기·스와이프·도망은 별도 범위로 다룬다. 닫힌 입 요구와 충돌하는 하악질·입술 핥기는 몸 자세 중심으로 각색한다. 발 미끄러짐·지면/사지 관통·몸통 분리·순간 좌우 반전·클리핑을 실제 렌더로 확인하고 모션 줄이기에서는 안정된 상태별 정지 포즈를 사용한다.
